### 发现并修正(v1.2.2)
1. **`sf_login.py` 会话保存路径严重 bug**:该文件自行推算 `ROOT = parents[2]` → `/Users/summer`,导致 `SESSION_DIR` = `/Users/summer/data/fetcher/sessions`(非项目目录);而抓取器读的是 `sf_core.SESSION_DIR` = `~/AQi-fetcher/data/fetcher/sessions`。**后果:重新登录后会话存到错误位置,抓取器仍用旧会话**——表现为"刚扫码却仍提示登录态过期",且不报错、只静默失效。修复:改为 `from sf_core import SESSION_DIR`。核查 `/Users/summer/data/` 不存在 → 该 bug 从未实际触发,项目内 3 个会话文件完好。
2. **新增 `SF/sf_check_session.py` 会话探活检查器**:三级判定(cookie 有效期 → 真实打开创作后台查是否跳登录页 → 调需登录接口),支持全平台/单平台/`--no-live`/`--show`。理由:cookie 未过期 ≠ 服务端仍认。
3. `sf_login.py` 清理过期注释(原注释称小红书以 `web_session` 为登录硬标志,与 `LOGIN_RULES` 实际使用的 creator 专用 cookie 矛盾,会误导后续 agent)。

### 规范固化(AGENTS.md)
新增两条硬性标准,防止同类 bug 复发:
- 路径必须从 `sf_core` 统一取(ROOT/DB_PATH/SESSION_DIR/ASSET_DIR/SNAPSHOT_DIR),**禁止**脚本内自行 `Path(__file__).resolve().parents[N]`。
- 任何"写文件到磁盘"的脚本,必须验证目标路径真实存在且正确,不能只看代码跑通。
